Recordings and live TV of an Enigma2 box (OpenWebif) on Samsung Smart TVs and Google TV.
First stable release, after 1.0 beta. Reports are welcome as issues; attach the box log
(`http://<box>/e2tvplayer/logs`).

## Changes since 1.0 beta

- Back from live TV to the programme guide lands on the channel watched last, also after
  changing channels during playback
- Live TV: a second OK hides the programme info and the bar at the bottom
- Samsung: a short break in the connection no longer turns live subtitles off until a restart
- Samsung: guide programme info (OK) shows line breaks correctly; a long text scrolls with ▲▼
- Samsung: lower key help at the bottom, three lines of programme info fit in the guide
- Samsung: the TOOLS settings fit on the screen (6 rows at a time, ▲/▼ for the rest) and
  stay on one line; the live arrow setting is called "Live TV ▲▼ CH+/−"

## Install

1. **Box** (OpenViX and other Enigma2 images with OpenWebif): copy
   `enigma2-plugin-extensions-e2tvplayer_1.1.0_all.ipk` to `/tmp` and run
   `opkg install /tmp/enigma2-plugin-extensions-e2tvplayer_1.1.0_all.ipk`, then restart the GUI.
   The plugin screen (Plugins → E2TVPlayer) and `http://<box>/e2tvplayer/` show the instructions
   for each TV.
2. **Google TV / Android TV**: install `E2TVPlayer.apk` (also served by the box). From 0.1.026 on
   the app offers updates itself when the box has a newer version.
3. **Samsung Tizen (2015–)**: install `E2TVPlayer.wgt`; the app loads its code from the box, so
   box updates reach it automatically.
4. **Samsung Smart TV 2011–2014 (Orsay)**: developer user + User App Sync with the box address,
   see the README. The app tells when the box has a newer version.

## Verified on

Samsung UE40H6275 (Orsay 2014), Samsung UE50AU7175 (Tizen 6.0), Chromecast with Google TV
