First public release of E2TVPlayer: recordings and live TV of an Enigma2 box (OpenWebif) on
Samsung Smart TVs and Google TV. Beta: it has been used daily on the devices below, but on few
other set-ups yet. Reports are welcome as issues; attach the box log (`http://<box>/e2tvplayer/logs`).

## Install

1. **Box** (OpenViX and other Enigma2 images with OpenWebif): copy
   `enigma2-plugin-extensions-e2tvplayer_1.0.0_all.ipk` to `/tmp` and run
   `opkg install /tmp/enigma2-plugin-extensions-e2tvplayer_1.0.0_all.ipk`, then restart the GUI.
   The plugin screen (Plugins → E2TVPlayer) and `http://<box>/e2tvplayer/` show the instructions
   for each TV.
2. **Google TV / Android TV**: install `E2TVPlayer.apk` (it is also served by the box). Later
   versions are offered by the app itself when the box has them.
3. **Samsung Tizen (2015–)**: install `E2TVPlayer.wgt` with Tizen Studio / sdb; the app loads
   its code from the box, so box updates reach it automatically.
4. **Samsung Smart TV 2011–2014 (Orsay)**: developer user + User App Sync with the box address,
   see the README. The app tells when the box has a newer version.

## What it does

- Recordings: folders, series, resume, delete, screenshots; DVB subtitles of recordings
  turned into pictures on the box
- Live TV with bouquets, INFO now/next, number keys, ▲▼ and CH+/− (direction is a setting)
- Programme guide (start view by default) with timers from the guide
- Automatic audio and subtitle choice: 1st and 2nd preference, original language,
  hard-of-hearing subtitles
- English, Finnish and Swedish; the language follows the TV or is chosen in the settings.
  New languages: `po/*.po`, see the README

## Verified on

Samsung UE40H6275 (Orsay 2014), Samsung UE50AU7175 (Tizen 6.0), Chromecast with Google TV
(Android 14), Vu+ Uno 4K SE with OpenViX.
